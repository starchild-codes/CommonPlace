# Changelog

## 0.1.0

Initial Commonplace release.

- journal shelf and custom covers
- page editor with plain, ruled, dotted, and grid paper
- six paper tones
- text, sticker, washi, paper, stamp, and image elements
- 46 original SVG decorative assets
- transform/layer/lock/duplicate/delete controls
- undo and redo
- local autosave
- focus/calm modes
- PNG page export
- JSON library backup/restore
- psychology, design, privacy, and roadmap documentation
