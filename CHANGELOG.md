# Changelog

## 0.2.0 — craft + reflection expansion

- expands the original craft drawer to 130+ generated SVG assets
- adds a dedicated Ephemera category with fictional tickets, receipts, postcards, labels, maps, photo strips, astronomy scraps, and more
- adds more botanical, celestial, cozy, food, letter, and object stickers
- adds additional washi, torn papers, and gentle rubber-stamp language
- adds an optional Reflect tool with effort filters and seven reflection doorways
- adds a feeling-word palette for emotion granularity without mood scoring
- adds prompts for observation vs interpretation, self-distancing, values, memory cues, and low-pressure closure
- keeps reflection explicitly non-diagnostic and non-therapeutic
- strengthens psychology documentation with evidence limits, including mixed findings for expressive writing
