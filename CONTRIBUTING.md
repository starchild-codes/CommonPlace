# Contributing

Commonplace welcomes small, reviewable changes.

## Before opening a PR

```bash
npm install
npm run check
```

## Asset contributions

Do not add copied Pinterest images, commercial sticker packs, scraped marketplace assets, or artwork with unclear redistribution rights.

Prefer:
- original SVG
- public-domain material with provenance
- self-created textures and patterns

## Product principle

Please do not add streaks, guilt notifications, social ranking, or engagement-oriented counters without first discussing how they fit the product's low-pressure design contract.
